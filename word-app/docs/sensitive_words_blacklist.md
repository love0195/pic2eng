# 敏感词汇黑名单

## 禁止使用的词汇

以下词汇由于可能涉及敏感内容，禁止在"看图学英语"应用中使用：

- police（警察）
- policeman（警察）
- policewoman（女警察）
- soldier（士兵）
- army（军队）
- military（军事）
- war（战争）
- weapon（武器）
- gun（枪）
- knife（刀）
- bomb（炸弹）
- terrorist（恐怖分子）
- violence（暴力）
- crime（犯罪）
- prison（监狱）
- jail（监狱）
- judge（法官）
- court（法庭）
- lawyer（律师）
- attorney（律师）
- lawsuit（诉讼）
- death（死亡）
- kill（杀害）
- murder（谋杀）
- suicide（自杀）
- accident（事故）
- disease（疾病）
- cancer（癌症）
- hospital（医院 - 虽然可以用，但要注意使用场景）
- doctor（医生 - 可以用，但要注意使用场景）
- nurse（护士 - 可以用，但要注意使用场景）

## 使用说明

1. 所有新增词汇都需要先检查是否在黑名单中
2. 如发现有遗漏的敏感词汇，请补充到本文件
3. 优先选择积极、正面、适合儿童学习的词汇
